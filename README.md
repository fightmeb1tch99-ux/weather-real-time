# 8-Bit Weather Widget

Стильный погодный виджет в стиле 8-бит с анимациями в реальном времени.

## Особенности
- **8-битный дизайн**: Пиксельная графика и шрифт 'Press Start 2P'.
- **Реальное время**: Данные о погоде подтягиваются через API `wttr.in`.
- **Анимации**: Динамические эффекты для солнца, облаков, дождя, снега и грозы.
- **Фоновое погружение**: Плывущие облака, дождь, снег и молнии на весь экран, соответствующие реальной погоде.
- **Эффект ветра**: Визуальные порывы ветра при высокой скорости ветра в реальности.
- **Авто-локация**: Автоматическое определение твоего города при запуске.
- **Поиск**: Возможность смены города вручную.

## Как использовать
Просто откройте `index.html` в любом современном браузере.

## Файлы
- `index.html` - Структура виджета.
- `style.css` - Стилизация и анимации.
- `script.js` - Логика получения данных и управления анимациями.
